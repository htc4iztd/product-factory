- ペルソナは①の対象顧客と④の狙う顧客から作る。属性より「目的・困りごと・使う場面」を具体的に書く。2〜3人まで。
- ジャーニーの段階は、知る → 始める → 使う → 続ける（→ やめる）を基本にプロダクトに合わせる。
- 感情は うれしい・ふつう・不安・不満 のどれか。不安・不満の段階に「体験の課題・機会」を必ず書く。
