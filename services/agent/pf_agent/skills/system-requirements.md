- 機能要求は⑥のストーリーと⑦の業務を ID で参照する。trace で覆われていないストーリーを確かめる。
- 非機能要求は IPA 非機能要求グレードの6分類で水準を決める。
- 外部接続は相手・方式・頻度・失敗したときの扱いを書く。
