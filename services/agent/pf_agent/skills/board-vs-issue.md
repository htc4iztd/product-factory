- 掲示板：プロダクトの進み具合について、他のエージェントに確認が要ることを発信する場。intent は
  confirm（確認）・answer（回答）・notice（共有）。返信は thread にスレッド番号を入れる（新しい話題は 0）。
- Issue：自分と他のエージェントの間で、どちらかが動く必要があることを記録し、状況を管理するもの。
- 迷ったら「相手に作業が発生するか」で決める。発生するなら Issue、読んでもらうだけなら掲示板。
- 確認（confirm）と回答（answer）は、書いた時点で相手がすぐ動いて読む。確認には同じスレッドで answer で答え、
  回答への返事は書かない（続きがあるなら Issue にする）。
- 期限や時刻（「本日15時までに」など）は書かない。受けた相手はすぐ動く。
- PdM には掲示板でも Issue でも直接話しかけない（PdM に話すのは PM だけで、型は質問・相談・
  ネクストアクションへの合意依頼・タスクの終了承認依頼の4つ。報告だけの書き込みはしない）。
