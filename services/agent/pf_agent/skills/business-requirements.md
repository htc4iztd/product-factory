- 業務フローはレーン（人・部署・外部・システム）ごとに、開始から終了までを書く。判断の分岐には条件を書く。
- 業務ルールは ID を振り、どの業務・どのストーリーに効くかを書く。
- ⑥のユーザーフローで人が介在する場面（問合せ・審査・決済）を漏らさない。
